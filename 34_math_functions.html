JavaScript Math Object

The JavaScript Math object allows you to perform mathematical tasks on numbers.
Unlike other objects, the Math object has no constructor. The Math object is static. All properties and methods can be used without creating a Math object first.
Math.PI;   // returns PI


Code Example Sample Output
Math.PI;

Math Properties (Constants)

JavaScript provides 8 mathematical constants that can be accessed as Math properties.


Code Example Sample Output
Math.E;   // returns Euler's number
Math.PI;   // returns PI
Math.SQRT2;   // returns the square root of 2
Math.SQRT1_2;   // returns the square root of 1/2
Math.LN2;   // returns the natural logarithm of 2
Math.LN10;   // returns the natural logarithm of 10
Math.LOG2E;   // returns base 2 logarithm of E
Math.LOG10E;   // returns base 10 logarithm of E

Math Methods

Math methods are written as a property of the Math object: Math.method(number)

Number to Integer

There are 4 common methods to round a number to an integer:
Math.round(x)   Returns x rounded to its nearest integer
Math.ceil(x)   Returns x rounded up to its nearest integer
Math.floor(x)   Returns x rounded down to its nearest integer
Math.trunc(x)   Returns the integer part of x (new in ES6)

Math.round()

Math.round(x) returns the value of x rounded to its nearest integer.


Code Example Sample Output
Math.round(4.6);
Math.round(4.5);
Math.round(4.4);

Math.ceil()

Math.ceil(x) returns the value of x rounded up to its nearest integer.


Code Example Sample Output
Math.ceil(4.9);
Math.ceil(4.7);
Math.ceil(4.4);
Math.ceil(4.2);
Math.ceil(-4.2);

Math.floor()

Math.floor(x) returns the value of x rounded down to its nearest integer.


Code Example Sample Output
Math.floor(4.9);
Math.floor(4.7);
Math.floor(4.4);
Math.floor(4.2);
Math.floor(-4.2);

Math.trunc()

Math.trunc(x) returns the integer part of x.


Code Example Sample Output
Math.trunc(4.9);
Math.trunc(4.7);
Math.trunc(4.4);
Math.trunc(4.2);
Math.trunc(-4.2);

Math.sign()

Math.sign(x) returns if x is negative, null or positive (-1, 0, 1).


Code Example Sample Output
Math.sign(-4);
Math.sign(0);
Math.sign(4);

Math.pow()

Math.pow(x, y) returns the value of x to the power of y.


Code Example Sample Output
Math.pow(8, 2);

Math.sqrt()

Math.sqrt(x) returns the square root of x.


Code Example Sample Output
Math.sqrt(64);

Math.abs()

Math.abs(x) returns the absolute (positive) value of x.


Code Example Sample Output
Math.abs(-4.7);

Math.sin()

Math.sin(x) returns the sine (a value between -1 and 1) of the angle x (given in radians).


Code Example Sample Output
Math.sin(90 * Math.PI / 180);   // returns 1 (the sine of 90 degrees)

Note: If you want to use degrees instead of radians, you have to convert degrees to radians: Angle in radians = Angle in degrees x PI / 180.

Math.cos()

Math.cos(x) returns the cosine (a value between -1 and 1) of the angle x (given in radians).


Code Example Sample Output
Math.cos(0 * Math.PI / 180);   // returns 1 (the cos of 0 degrees)

Math.min() and Math.max()

Math.min() and Math.max() can be used to find the lowest or highest value in a list of arguments.


Code Example Sample Output
Math.min(0, 150, 30, 20, -8, -200);
Math.max(0, 150, 30, 20, -8, -200);

Math.random()

Math.random() returns a random number between 0 (inclusive), and 1 (exclusive).


Code Example Sample Output
Math.random();

Note: Math.random() is always used together with Math.floor() to return a random integer. This is covered in detail on the next page, "JS - Random".

The Math.log() Method

Math.log(x) returns the natural logarithm of x.


Code Example Sample Output
Math.log(1);
Math.log(2);
Math.log(3);
Math.log(10);

The Math.log2() Method

Math.log2(x) returns the base 2 logarithm of x.


Code Example Sample Output
Math.log2(8);

The Math.log10() Method

Math.log10(x) returns the base 10 logarithm of x.


Code Example Sample Output
Math.log10(1000);
