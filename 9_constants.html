JavaScript const

The const keyword was introduced in ES6 (2015).
Variables defined with const cannot be Redeclared.
Variables defined with const cannot be Reassigned.
Variables defined with const have Block Scope.


Cannot be Reassigned

A const variable cannot be reassigned:


Code Example Sample Output
const PI = 3.141592653589793;
PI = 3.14;      // This will give an error
PI = PI + 10;      // This will also give an error 		TypeError: Assignment to constant variable.

Must be Assigned

JavaScript const variables must be assigned a value when they are declared:


Code Example Sample Output
const PI = 3.14159265359;      // Correct Works correctly.
const PI;                  // Incorrect
PI = 3.14159265359; 		SyntaxError: Missing initializer in const declaration.

Note: Variables defined with var or let can be declared without being assigned a value. Not so with const.


When to use JavaScript const

Always declare a variable with const when you know that the value should not be changed.
Use const when you declare:

  • A new Array
  • A new Object
  • A new Function
  • A new RegExp

Block Scope

Variables declared with const have Block Scope, like variables declared with let.


Code Example Sample Output
{
  const x = 2;
}
// x can NOT be used here 		x is only available inside the block.

Redeclaring

JavaScript const variables cannot be Redeclared.
A const variable cannot be redeclared, in the same scope, using var, let, or const:


Code Example Sample Output
var x = 2;          // Allowed
const x = 2;        // Not allowed 		SyntaxError: Identifier 'x' has already been declared.
let x = 2;          // Allowed
const x = 2;        // Not allowed 		SyntaxError: Identifier 'x' has already been declared.
const x = 2;      // Allowed
const x = 2;      // Not allowed 		SyntaxError: Identifier 'x' has already been declared.

A const variable can be redeclared in a different scope or in a different block:


Code Example Sample Output
const x = 2;      // Allowed
{
  const x = 3;      // Allowed
}
{
  const x = 4;      // Allowed
} 		No error. Each block has its own x.

JavaScript Constant Objects and Arrays

The keyword const is a little misleading.
It does not define a constant value. It defines a constant reference to a value.
Because of this you can NOT:

  • Reassign a constant value
  • Reassign a constant array
  • Reassign a constant object

But you CAN:

  • Change the elements of constant array
  • Change the properties of constant object

Constant Arrays

You can change the elements of a constant array:


Code Example Sample Output
<!DOCTYPE html>
<html>
<body>

  <h2>JavaScript Constants</h2>

  <p>You can change the elements of a constant array:</p>

  <p id="demo"></p>

  <script>
    // You can create a const array:
    const cars = ["Saab", "Volvo", "BMW"];

    // You can change an element:
    cars[0] = "Toyota";

    // You can add an element:
    cars.push("Audi");

    document.getElementById("demo").innerHTML = cars;
  </script>

</body>
</html>

JavaScript Constants

You can change the elements of a constant array:

Toyota,Volvo,BMW,Audi

But you can NOT reassign the array:


Code Example Sample Output
const cars = ["Saab", "Volvo", "BMW"];
cars = ["Toyota", "Volvo", "Audi"];    // ERROR 		TypeError: Assignment to constant variable.

Constant Objects

You can change the properties of a constant object:


Code Example Sample Output
<!DOCTYPE html>
<html>
<body>

  <h2>JavaScript Constants</h2>

  <p>You can change the properties of a constant object:</p>

  <p id="demo"></p>

  <script>
    // You can create a const object:
    const car = {type:"Fiat", model:"500", color:"white"};

    // You can change a property:
    car.color = "red";

    // You can add a property:
    car.owner = "Johnson";

    document.getElementById("demo").innerHTML =
    "Car color is " + car.color + ", owned by " + car.owner;
  </script>

</body>
</html>

JavaScript Constants

You can change the properties of a constant object:

Car color is red, owned by Johnson

But you can NOT reassign the object:


Code Example Sample Output
const car = {type:"Fiat", model:"500", color:"white"};
car = {type:"Volvo", model:"EX60", color:"red"};    // ERROR 		TypeError: Assignment to constant variable.
