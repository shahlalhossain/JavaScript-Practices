JavaScript Arrays

An array is a special variable, which can hold more than one value:


Code Example Sample Output
const cars = ["Saab", "Volvo", "BMW"]; An array of three car names.

Why Use Arrays?

If you have a list of items (a list of car names, for example), storing the cars in single variables could look like this:


Code Example Sample Output
let car1 = "Saab";
let car2 = "Volvo";
let car3 = "BMW"; 		Three separate variables.

What if you want to loop through the cars and find a specific one? And what if you had not 3 cars, but 300?
The solution is an array. An array can hold many values under a single name, and you can access the values by referring to an index number.


Creating an Array

Using an array literal is the easiest way to create a JavaScript Array:


Code Example Sample Output
const cars = ["Saab", "Volvo", "BMW"]; An array literal.

Spaces and line breaks are not important. A declaration can span multiple lines:


Code Example Sample Output
const cars = [
  "Saab",
  "Volvo",
  "BMW"
]; 		Same array, written on multiple lines.

Note: It is a common practice to declare arrays with the const keyword.


Using the JavaScript Keyword new

The following example also creates an array, and assigns values to it:


Code Example Sample Output
const cars = new Array("Saab", "Volvo", "BMW"); Same result as the array literal above.

Note: The two examples above do exactly the same. There is no need to use new Array(). For simplicity, readability and execution speed, use the array literal method.


Accessing Array Elements

You access an array element by referring to the index number:


Code Example Sample Output
const cars = ["Saab", "Volvo", "BMW"];
let car = cars[0]; 		Saab

Note: Array indexes start with 0. [0] is the first element. [1] is the second element.


Changing an Array Element

This statement changes the value of the first element in cars:


Code Example Sample Output
const cars = ["Saab", "Volvo", "BMW"];
cars[0] = "Opel"; 		Opel,Volvo,BMW

Access the Full Array

With JavaScript, the full array can be accessed by referring to the array name:


Code Example Sample Output
const cars = ["Saab", "Volvo", "BMW"];
document.getElementById("demo").innerHTML = cars; 		Saab,Volvo,BMW

Arrays are Objects

Arrays are a special type of objects. The typeof operator in JavaScript returns "object" for arrays.


Code Example Sample Output
const cars = ["Saab", "Volvo", "BMW"];
typeof cars; 		object

But, JavaScript arrays are best described as arrays.
Arrays use numbers to access its "elements". In this example, person[0] returns John:


Code Example Sample Output
const person = ["John", "Doe", 46]; An array.

Objects use names to access its "members". In this example, person.firstName returns John:


Code Example Sample Output
const person = {firstName:"John", lastName:"Doe", age:46}; An object.

Array Elements Can Be Objects

JavaScript variables can be objects. Arrays are special kinds of objects.
Because of this, you can have variables of different types in the same Array. You can have objects in an Array. You can have functions in an Array. You can have arrays in an Array:


Code Example Sample Output
myArray[0] = Date.now;
myArray[1] = myFunction;
myArray[2] = myCars; 		An array can hold dates, functions, and other arrays.

Array Properties and Methods

The real strength of JavaScript arrays are the built-in array properties and methods:


Code Example Sample Output
const cars = ["Saab", "Volvo", "BMW"];
cars.length; 		3
const cars = ["Saab", "Volvo", "BMW"];
cars.sort(); 		BMW,Saab,Volvo

You will learn more about arrays methods in the next chapter.


The length Property

The length property of an array returns the length of an array (the number of array elements).


Code Example Sample Output
const fruits = ["Banana", "Orange", "Apple", "Mango"];
let length = fruits.length; 		4

Note: The length property is always one more than the highest array index.


Accessing the First Array Element


Code Example Sample Output
const fruits = ["Banana", "Orange", "Apple", "Mango"];
let fruit = fruits[0]; 		Banana

Accessing the Last Array Element


Code Example Sample Output
const fruits = ["Banana", "Orange", "Apple", "Mango"];
let fruit = fruits[fruits.length - 1]; 		Mango

Looping Array Elements

One way to loop through an array, is using a for loop:


Code Example Sample Output
const fruits = ["Banana", "Orange", "Apple", "Mango"];
let text = "";
for (let i = 0; i < fruits.length; i++) {
  text += "<li>" + fruits[i] + "</li>";
}

You can also use the Array.forEach() function:


Code Example Sample Output
const fruits = ["Banana", "Orange", "Apple", "Mango"];
let text = "";
fruits.forEach(myFunction);

function myFunction(value) {
  text += "<li>" + value + "</li>";
}

Adding Array Elements

The easiest way to add a new element to an array is using the push() method:


Code Example Sample Output
const fruits = ["Banana", "Orange", "Apple", "Mango"];
fruits.push("Lemon"); 		Banana,Orange,Apple,Mango,Lemon

Adding a new element to an array using a new index is also possible, but it can break the array and should be avoided:


Code Example Sample Output
const fruits = ["Banana", "Orange", "Apple", "Mango"];
fruits[fruits.length] = "Lemon"; 		Banana,Orange,Apple,Mango,Lemon

Associative Arrays

Many programming languages support arrays with named indexes. Arrays with named indexes are called associative arrays (or hashes).
JavaScript does NOT support arrays with named indexes. In JavaScript, arrays always use numbered indexes.


Code Example Sample Output
const person = [];
person[0] = "John";
person[1] = "Doe";
person[2] = 46;
person.length;    // 3
person[0];        // John 		Works as expected: length is 3, person[0] is "John".
const person = [];
person["firstName"] = "John";
person["lastName"] = "Doe";
person["age"] = 46;
person.length;    // 0
person[0];        // undefined 		Does not behave as an array. length is 0, person[0] is undefined.

Warning: If you use named indexes, JavaScript will redefine the array to a standard object. After that, some array methods and properties will produce incorrect results.


The Difference Between Arrays and Objects

In JavaScript, arrays use numbered indexes.
In JavaScript, objects use named indexes.

Arrays are a special kind of objects, with numbered indexes.


When to Use Arrays. When to use Objects.

  • JavaScript does not support associative arrays.
  • You should use objects when you want the element names to be strings (text).
  • You should use arrays when you want the element names to be numbers.

JavaScript new Array()

JavaScript has a built in array constructor new Array(). But you should avoid using it. new Array() and new Array(car1, car2, car3) work the same as the array literal.


Code Example Sample Output
const points = new Array(40, 100, 1, 5, 25, 10); Same as array literal.

There is one exception with a single numeric parameter: new Array(number) creates an array with an empty slot, and sets the length property to number.


Code Example Sample Output
const points = new Array(40); Creates an array with length 40, and no elements.

Note: To keep things simple, readable and fast, use the array literal syntax.


How to Recognize an Array

A common question is: How do I know if a variable is an array?
The problem is that the JavaScript operator typeof returns "object":


Code Example Sample Output
const fruits = ["Banana", "Orange", "Apple"];
typeof fruits; 		object

The typeof operator returns object because a JavaScript array is an object.
To solve this problem, ECMAScript 5 (2009) defined a new method Array.isArray():


Code Example Sample Output
const fruits = ["Banana", "Orange", "Apple"];
Array.isArray(fruits); 		true
