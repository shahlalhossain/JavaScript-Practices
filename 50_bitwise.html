JavaScript Bitwise Operations

Bitwise operators treat their operands as a set of 32 bits (zeros and ones), rather than as decimal, hexadecimal, or octal numbers.

JavaScript Bitwise Operators

Bitwise operators perform their operations on binary representations.


Operator Description Example
&ANDx = 5 & 1
|ORx = 5 | 1
~NOTx = ~5
^XORx = 5 ^ 1
<<Left shiftx = 5 << 1
>>Right shiftx = 5 >> 1
>>>Unsigned right shiftx = 5 >>> 1

Note: Examples above uses 4 bits un-signed examples. But JavaScript uses 32-bit signed numbers. Because of this, in JavaScript, ~ 5 will not return 10. It will return -6.

Examples

Operator results for the numbers 5 (101) and 1 (001):


Code Example Sample Output
5 & 1;
5 | 1;
~5;
5 ^ 1;
5 << 1;
5 >> 1;
5 >>> 1;

JavaScript Uses 32 bits Bitwise Operands

JavaScript stores numbers as 64 bits floating point numbers, but all bitwise operations are performed on 32 bits binary numbers.
Before a bitwise operation is performed, JavaScript converts numbers to 32-bit signed integers. After the bitwise operation is performed, the result is converted back to 64-bit JavaScript numbers.
The examples above uses 4 bits unsigned binary numbers. Because of this ~5 is displayed as 10. Since JavaScript uses 32-bit signed integers, it will not display 10. It will display -6.


Code Example Sample Output
5 = 00000000000000000000000000000101
~5 = 11111111111111111111111111111010

JavaScript Bitwise AND

When a bitwise AND operation is performed on a pair of bits, it returns 1 if both bits are 1.


Code Example Sample Output
1111 & 0000;
1111 & 0001;
1111 & 0010;
1111 & 0100;

JavaScript Bitwise OR

When a bitwise OR operation is performed on a pair of bits, it returns 1 if one of the bits is 1.


Code Example Sample Output
1111 | 0000;
1111 | 0001;
1111 | 0010;
1111 | 0100;

JavaScript Bitwise XOR

When a bitwise XOR operation is performed on a pair of bits, it returns 1 if the bits are different.


Code Example Sample Output
1111 ^ 0000;
1111 ^ 0001;
1111 ^ 0010;
1111 ^ 0100;

JavaScript Bitwise AND (&)

Bitwise ANDing any number n with 0 results in 0.


Code Example Sample Output
let x = 5 & 1;

JavaScript Bitwise OR (|)

Bitwise ORing any number n with 0 results in n.


Code Example Sample Output
let x = 5 | 1;

JavaScript Bitwise XOR (^)

Bitwise XORing any number n with 0 results in n.


Code Example Sample Output
let x = 5 ^ 1;

JavaScript Bitwise NOT (~)

The bitwise NOT operator inverts all of the bits of a number.


Code Example Sample Output
let x = ~5;

JavaScript (Zero Fill) Bitwise Left Shift (<<)

This operator shifts the first operand the specified number of bits to the left. Excess bits shifted off to the left are discarded. Zero bits are shifted in from the right.


Code Example Sample Output
let x = 5 << 1;

JavaScript (Sign Preserving) Bitwise Right Shift (>>)

This operator shifts the first operand the specified number of bits to the right. Excess bits shifted off to the right are discarded. Copies of the leftmost bit are shifted in from the left.


Code Example Sample Output
let x = -5 >> 1;

JavaScript (Zero Fill) Right Shift (>>>)

This operator shifts the first operand the specified number of bits to the right. Excess bits shifted off to the right are discarded. Zero bits are shifted in from the left.


Code Example Sample Output
let x = 5 >>> 1;

Shift Assignment Operators

Shift assignment operators shift and assign a new value, in one operation.


Operator Example Same As
<<=x <<= yx = x << y
>>=x >>= yx = x >> y
>>>=x >>>= yx = x >>> y

The <<= Operator

The <<= operator shifts the bits of x to the left and reassigns the result to x.


Code Example Sample Output
let x = -100;
x <<= 5;

The >>= Operator

The >>= operator shifts the bits of x to the right and reassigns the result to x.


Code Example Sample Output
let x = -100;
x >>= 5;

The >>>= Operator

The >>>= operator shifts the bits of x to the right (zero fill) and reassigns the result to x.


Code Example Sample Output
let x = -100;
x >>>= 5;

Bitwise Assignment Operators

Bitwise assignment operators assign a value based on a bitwise operation.


Operator Example Same As
&=x &= yx = x & y
^=x ^= yx = x ^ y
|=x |= yx = x | y

The &= Operator

The &= operator ANDs x with y and reassigns the result to x.


Code Example Sample Output
let x = 10;
x &= 5;

The |= Operator

The |= operator ORs x with y and reassigns the result to x.


Code Example Sample Output
let x = 10;
x |= 5;

The ^= Operator

The ^= operator XORs x with y and reassigns the result to x.


Code Example Sample Output
let x = 10;
x ^= 5;

Binary Numbers

Binary numbers with only one bit set are easy to understand:
00000000000000000000000000000001 is 1, 00000000000000000000000000000010 is 2, 00000000000000000000000000000100 is 4, and so on, doubling each time.
Binary numbers with more than one bit set are added together: 00000000000000000000000000000101 is 4 + 1 = 5, 00000000000000000000000000001101 is 8 + 4 + 1 = 13.

Negative numbers are stored as the two's complement of their positive counterpart: 11111111111111111111111111111011 is -5, 11111111111111111111111111111010 is -6, 11111111111111111111111111011000 is -40.

Converting Decimal to Binary

To convert a (positive) decimal number to a binary string, you can use this code:


Code Example Sample Output
function dec2bin(dec) {
  return (dec >>> 0).toString(2);
}
dec2bin(45);

Converting Binary to Decimal

To convert a binary string to a (positive) decimal number, you can use this code:


Code Example Sample Output
function bin2dec(bin) {
  return parseInt(bin, 2).toString(10);
}
bin2dec("101101");
