JavaScript Numbers

JavaScript has only one type of number. Numbers can be written with, or without decimals.


Code Example Sample Output
let x = 3.14;    // A number with decimals
let y = 3;        // A number without decimals 		Both x and y are of type "number".

Extra large or extra small numbers can be written with scientific (exponential) notation:


Code Example Sample Output
let x = 123e5;    // 12300000
let y = 123e-5;   // 0.00123 		Scientific notation examples.

JavaScript Numbers are Always 64-bit Floating Point

Unlike many other programming languages, JavaScript does not define different types of numbers, like integers, short, long, floating-point etc.
JavaScript numbers are always stored as double precision floating point numbers, following the international IEEE 754 standard.

This format stores numbers in 64 bits, where the number (the fraction) is stored in bits 0 to 51, the exponent in bits 52 to 62, and the sign in bit 63.


Precision

Integers (numbers without a period or exponent notation) are accurate up to 15 digits.


Code Example Sample Output
let x = 999999999999999;    // x will be 999999999999999
let y = 9999999999999999;   // y will be 10000000000000000 		x is accurate, y loses precision.

The maximum number of decimals is 17, but floating point arithmetic is not always 100% accurate:


Code Example Sample Output
let x = 0.2 + 0.1; 0.30000000000000004

To solve the problem above, it helps to multiply and divide:


Code Example Sample Output
let x = (0.2 * 10 + 0.1 * 10) / 10; 0.3

Adding Numbers and Strings

JavaScript uses the + operator for both addition and concatenation. Numbers are added. Strings are concatenated.


Code Example Sample Output
let x = 10 + 5; x is 15 (a number).
let x = "10" + "5"; x is "105" (a string).

If you add a number and a string, the result will be a string:


Code Example Sample Output
let x = 10 + "5"; x is "105" (a string).
let x = "10" + 5; x is "105" (a string).

Note: A common mistake is to expect this result to be 15: let x = 10;
let y = 5;
let z = "The result is: " + x + y; Since the string comes first, JavaScript evaluates the expression left to right: "The result is: " + 10 is first converted to the string "The result is: 10", then + 5 is appended, giving "The result is: 105".


Numeric Strings

JavaScript strings can have numeric content:


Code Example Sample Output
let x = "100";
let y = "10";
let z = x / y;		 10
let x = "100";
let y = "10";
let z = x * y;		 1000
let x = "100";
let y = "10";
let z = x - y;		 90
let x = "100";
let y = "10";
let z = x + y;		 10010

Note: JavaScript will try to convert strings to numbers in all numeric operations, but the last example does not work because + is also used for string concatenation.


NaN - Not a Number

NaN is a JavaScript reserved word indicating that a number is not a legal number.


Code Example Sample Output
let x = 100 / "Apple"; NaN

However, if the string is numeric, the result will be a number:


Code Example Sample Output
let x = 100 / "10"; 10

You can use the global JavaScript function isNaN() to find out if a value is a not a number:


Code Example Sample Output
let x = 100 / "Apple";
isNaN(x); 		true

Note: NaN is a number: typeof NaN returns "number". You cannot compare NaN against itself: NaN === NaN returns false.


Infinity

Infinity (or -Infinity) is the value JavaScript will return if you calculate a number outside the largest possible number.


Code Example Sample Output
let myNumber = 2;
while (myNumber != Infinity) {
  myNumber = myNumber * myNumber;
}		 myNumber eventually becomes Infinity.
let x = 2 / 0; Infinity
let x = -2 / 0; -Infinity

Note: typeof Infinity returns "number".


Hexadecimal

JavaScript interprets numeric constants as hexadecimal if they are preceded by 0x.


Code Example Sample Output
let x = 0xFF; 255

Note: Never write a number with a leading zero (like 07), as some JavaScript versions interpret numbers as octal if they are written with a leading zero.


Numeric Separators

A numeric separator (_) makes it easier for humans to read numeric values, especially on large numbers with lots of digits.


Code Example Sample Output
let billion = 1_000_000_000; billion is 1000000000.

Numeric separators can also be used with decimal, binary, hex, and BigInt numbers.

Note: Numeric separators are not supported in JSON and are not allowed in some places, like right after a leading 0, or adjacent to a decimal point.


JavaScript Numbers as Objects

Normally JavaScript numbers are primitive values created from literals: let x = 123;
But numbers can also be defined as objects with the keyword new: let y = new Number(123);


Code Example Sample Output
let x = 123;
let y = new Number(123); 		typeof x is "number", typeof y is "object".

Note: Do not create Number objects. It slows down execution speed, and produces side effects. The new keyword complicates the code. Comparing two JavaScript objects always returns false.
