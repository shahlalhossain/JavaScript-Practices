Regular Expressions

A regular expression is a sequence of characters that forms a search pattern. When you search for data in a text, you can use this search pattern to describe what you are searching for.
A regular expression can be a single character, or a more complicated pattern. Regular expressions can be used to perform all types of text search and text replace operations.


Code Example Sample Output
let text = "Visit W3Schools";
let n = text.search(/w3schools/i);

Regular Expression Syntax

/pattern/modifiers;
pattern describes a pattern of an expression, modifiers can modify the search to be, for instance, global or case insensitive.

Using String Methods

In JavaScript, regular expressions are often used with the two string methods: match() and replace(), and the search() method that uses a regular expression.


Method Description
match()Returns an array containing all of the matches, including capturing groups, or null if no match is found
replace()Returns a new string with some or all matches of a pattern replaced by a replacement
search()Returns the index of the first match between a regular expression and a string, or -1 if no match is found

Using String match()

The match() method searches a string for a match against a regular expression, and returns the matches.


Code Example Sample Output
let text = "Visit W3Schools";
let n = text.match(/W3schools/);

Note: Because there is no "i" modifier, "W3schools" (with lower case "s") does not match "W3Schools" (with upper case "S"), so the result is null.

Using String replace()

The replace() method replaces a specified value with another value in a string.


Code Example Sample Output
let text = "Visit Microsoft!";
let result = text.replace(/Microsoft/i, "W3Schools");

Note: By using a regular expression with the "i" flag, the case of the string to be replaced is ignored.

Using String search()

The search() method searches a string for a specified value and returns the position of the match.


Code Example Sample Output
let text = "Visit W3Schools";
let n = text.search(/W3Schools/);

RegExp Alternation (OR)

The | metacharacter is used to specify alternative patterns.


Code Example Sample Output
let text = "Black, white, red, green, blue, yellow.";
let result = text.match(/red|green|blue/g);

JavaScript Regex Flags

Flags can be used to perform case-insensitive and global searches:


Flag Description
gGlobal search (find all matches, not just the first)
iCase-insensitive search
uEnables Unicode support

The /g Flag (Global)

The g flag is used to find all matches, rather than just the first match.


Code Example Sample Output
let text = "Is this all there is?";
const pattern = /is/g;
let result = text.match(pattern);

The /i Flag (Insensitive)

The i flag is used to perform case-insensitive matching.


Code Example Sample Output
let text = "Visit W3Schools";
const pattern = /w3schools/i;
let result = text.match(pattern);

RegExp Metacharacters

Metacharacters are characters with a special meaning.


Metacharacter Description
\dFind a digit
\wFind a word character
\sFind a whitespace character

RegExp \d (digits) Metacharacter

The \d metacharacter is used to find a digit in a string.


Code Example Sample Output
let text = "Give 100%!";
const pattern = /\d/g;
let result = text.match(pattern);

RegExp \w (word) Metacharacter

The \w metacharacter is used to find a word character. A word character is a character a-z, A-Z, 0-9, including the underscore character.


Code Example Sample Output
let text = "Give 100%!";
const pattern = /\w/g;
let result = text.match(pattern);

JavaScript RegExp Quantifiers

Quantifiers define quantities.


Quantifier Description
n+Matches any string that contains at least one n
n*Matches any string that contains zero or more occurrences of n
n?Matches any string that contains zero or one occurrences of n

The ? Quantifier

The ? quantifier makes the preceding character optional.


Code Example Sample Output
let text = "1, 100 or 1000?";
const pattern = /10?/g;
let result = text.match(pattern);

Regular Expression Assertions

Assertions include boundaries, which indicate the beginnings and endings of lines and words, and other patterns indicating in some way that a match is possible.


Assertion Description
^Start of string
$End of string
\bA word boundary
(?=...)Lookahead assertion
(?<=...)Lookbehind assertion

RegExp ^ Metacharacter

The ^ metacharacter is used to find a match at the beginning of a string.


Code Example Sample Output
const pattern = /^W3Schools/;
let text = "W3Schools Tutorial";
let result = pattern.test(text);   // true
const pattern = /^W3Schools/;
let text = "Hello W3Schools";
let result = pattern.test(text);   // false

RegExp $ Metacharacter

The $ metacharacter is used to find a match at the end of a string.


Code Example Sample Output
const pattern = /W3Schools$/;
let text = "Hello W3Schools";
let result = pattern.test(text);   // true
const pattern = /W3Schools$/;
let text = "W3Schools tutorial";
let result = pattern.test(text);   // false

JavaScript RegExp Character Classes

Character classes define a set of characters, any of which can occur in an input string to fulfill a match.


Expression Description
[abc]Find any of the characters between the brackets
[0-9]Find any of the digits between the brackets
(x|y)Find any of the alternatives separated with |

Example [0-9]

The character class [0-9] can be used to find digits in a text.


Code Example Sample Output
let text = "More than 1000 times";
const pattern = /[0-9]/g;
let result = text.match(pattern);
