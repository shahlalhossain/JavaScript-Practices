Run a Function After a Delay

With JavaScript, it is possible to execute code, not immediately, but after a time interval. This is called "timing events".


Function Description
setTimeout()Runs a function once, after a delay
setInterval()Runs a function repeatedly, with a delay between each call
clearTimeout()Cancels a timer set with setTimeout()
clearInterval()Cancels a timer set with setInterval()

The setTimeout() Function

Syntax
setTimeout(function, milliseconds);


Code Example Sample Output
function myFunction() {
  document.getElementById("demo1").innerHTML = "I love You !!";
}
setTimeout(myFunction, 1000);

Passing a Function

Pass the name of the function, not a call to it. Using parentheses calls the function immediately.


Code Example Sample Output
setTimeout(myFunction, 3000);   // Correct
setTimeout(myFunction(), 3000);   // Incorrect, calls myFunction immediately

Using an Anonymous Function

You can also pass an anonymous function directly to setTimeout().


Code Example Sample Output
setTimeout(function() {
  document.getElementById("demo4").innerHTML = "I love You !!";
}, 1000);

Timers Do Not Pause JavaScript

setTimeout() does not pause the execution of the rest of the code. The timer callback always runs after the current script finishes.


Code Example Sample Output
let order = ["Start"];
setTimeout(function() { order.push("Timer"); }, 500);
order.push("End");

A Zero Delay

Using setTimeout() with a delay of 0 ms still defers the callback until after the current script finishes.


Code Example Sample Output
let order = ["Start"];
setTimeout(function() { order.push("Timer"); }, 0);
order.push("End");

The Delay Is a Minimum

The delay parameter specifies the minimum time before the callback runs; it is not a guarantee. A long-running synchronous task will delay the timer further.

Canceling a Timeout

clearTimeout() stops the execution of the function specified in setTimeout().


Code Example Sample Output
let myTimeout;
function myStart() {
  myTimeout = setTimeout(myFunction, 3000);
}
function myStop() {
  clearTimeout(myTimeout);
}

The setInterval() Function

Syntax
setInterval(function, milliseconds);
setInterval() repeats a given function at every given time interval.


Code Example Sample Output
setInterval(function() {
  const d = new Date();
  document.getElementById("demo8").innerHTML = d.toLocaleTimeString();
}, 1000);

Canceling an Interval

Syntax
clearInterval(intervalId);
The "Stop Clock" button above calls clearInterval() with the interval's ID, stopping the recurring updates.

Timeout or Interval?

Use the right tool for the task:


Task Function
Run once after a delaysetTimeout()
Run repeatedlysetInterval()
Cancel a delayed callclearTimeout()
Stop a repeating callclearInterval()

Passing Arguments

Extra arguments to setTimeout() (after the delay) are passed through to the callback function.


Code Example Sample Output
function showMessage(greeting, name) {
  document.getElementById("demo9").innerHTML = greeting + ", " + name;
}
setTimeout(showMessage, 1000, "Hello", "John");

Repeated setTimeout()

A function can reschedule itself with setTimeout() to create a repeating timer, as an alternative to setInterval().


Code Example Sample Output
let count10 = 0;
function repeat() {
  count10++;
  document.getElementById("demo10").innerHTML = "Tick " + count10;
  if (count10 < 3) setTimeout(repeat, 300);
}
setTimeout(repeat, 300);

A Countdown Example

This example counts down from 10 to 0, using setInterval(), stopping automatically at zero.


Code Example Sample Output
let count = 10;
const id = setInterval(function() {
  document.getElementById("demo11").innerHTML = count;
  count--;
  if (count < 0) clearInterval(id);
}, 200);

Avoid Strings as Timer Code

Never use strings as the first argument to setTimeout() or setInterval(): it evaluates like eval(), which is a security risk.


Code Example Sample Output
setTimeout("myFunction()", 1000);   // Not recommended
setTimeout(myFunction, 1000);   // Recommended

Timers Run on the Main Thread

JavaScript timers run on the same single thread as the rest of your page. A heavy, long-running callback can freeze the page's responsiveness while it runs.

Common Timer Mistakes

Calling the function immediately by adding () instead of passing its name. Losing the timer ID, making it impossible to cancel later. Starting duplicate intervals by not checking if one is already running. Assuming the delay is exact, rather than a minimum. Forgetting to call clearInterval() when a repeating timer is no longer needed.

A Slide Show Example

Cycles through a sequence every interval, with Start/Stop buttons.


Code Example Sample Output
const slides = ["Slide 1", "Slide 2", "Slide 3"];
let slideIndex = 0;
let slideTimer;
function showSlide() {
  document.getElementById("demo14").innerHTML = slides[slideIndex];
  slideIndex = (slideIndex + 1) % slides.length;
}

Timers and Asynchronous JavaScript

Timers are one of the simplest examples of asynchronous behavior in JavaScript: scheduling work to happen later, without blocking the rest of the script. setTimeout() and setInterval() work alongside callbacks, Promises, and async/await to coordinate work that happens over time.
