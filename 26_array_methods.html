JavaScript Array Methods

JavaScript array methods help you to work with arrays.


Converting Arrays to Strings

The JavaScript method toString() converts an array to a string of (comma separated) array values.


Code Example Sample Output
const fruits = ["Banana", "Orange", "Apple", "Mango"];
document.getElementById("demo").innerHTML = fruits.toString(); 		Banana,Orange,Apple,Mango

The join() method also joins all array elements into a string. It behaves just like toString(), but you can also specify the separator:


Code Example Sample Output
const fruits = ["Banana", "Orange", "Apple", "Mango"];
document.getElementById("demo").innerHTML = fruits.join(" * "); 		Banana * Orange * Apple * Mango

Popping and Pushing

When working with arrays, it is easy to remove elements and add new elements.
Popping and pushing is what happens when you remove and add elements, to and from, an array.

The pop() method removes the last element from an array:


Code Example Sample Output
const fruits = ["Banana", "Orange", "Apple", "Mango"];
fruits.pop(); 		Banana,Orange,Apple

The pop() method returns the value that was "popped out":


Code Example Sample Output
const fruits = ["Banana", "Orange", "Apple", "Mango"];
let fruit = fruits.pop(); 		Mango

The push() method (adds a new element to an array) at the end:


Code Example Sample Output
const fruits = ["Banana", "Orange", "Apple", "Mango"];
fruits.push("Kiwi"); 		Banana,Orange,Apple,Mango,Kiwi

The push() method returns the new array length:


Code Example Sample Output
const fruits = ["Banana", "Orange", "Apple", "Mango"];
let length = fruits.push("Kiwi"); 		5

Shifting Elements

Shifting is equivalent to popping, but working on the first element instead of the last.
The shift() method removes the first array element and "shifts" all other elements to a lower index:


Code Example Sample Output
const fruits = ["Banana", "Orange", "Apple", "Mango"];
fruits.shift(); 		Orange,Apple,Mango

The shift() method returns the value that was "shifted out":


Code Example Sample Output
const fruits = ["Banana", "Orange", "Apple", "Mango"];
let fruit = fruits.shift(); 		Banana

The unshift() method adds a new element to an array, at the beginning, and "unshifts" older elements:


Code Example Sample Output
const fruits = ["Banana", "Orange", "Apple", "Mango"];
fruits.unshift("Lemon"); 		Lemon,Banana,Orange,Apple,Mango

The unshift() method returns the new array length:


Code Example Sample Output
const fruits = ["Banana", "Orange", "Apple", "Mango"];
let length = fruits.unshift("Lemon"); 		5

Changing Elements

Array elements are accessed using their index number. Array indexes start with 0. [0] is the first element, [1] is the second, [2] is the third...


Code Example Sample Output
const fruits = ["Banana", "Orange", "Apple", "Mango"];
fruits[0] = "Kiwi"; 		Kiwi,Orange,Apple,Mango

Deleting Elements

Since JavaScript arrays are objects, you can use the delete operator to delete elements from an array:


Code Example Sample Output
const fruits = ["Banana", "Orange", "Apple", "Mango"];
delete fruits[0]; 		,Orange,Apple,Mango

Warning: Using delete leaves undefined holes in the array. Use pop() or shift() instead.


Merging (Concatenating) Arrays

The concat() method creates a new array by merging (concatenating) existing arrays:


Code Example Sample Output
const myGirls = ["Cecilie", "Lone"];
const myBoys = ["Emil", "Tobias", "Linus"];
const myChildren = myGirls.concat(myBoys); 		Cecilie,Lone,Emil,Tobias,Linus

The concat() method does not change the existing arrays. It always returns a new array.
The concat() method can take any number of array arguments:


Code Example Sample Output
const arr1 = ["Cecilie", "Lone"];
const arr2 = ["Emil", "Tobias", "Linus"];
const arr3 = ["Robin", "Morgan"];
const myChildren = arr1.concat(arr2, arr3); 		Cecilie,Lone,Emil,Tobias,Linus,Robin,Morgan

The concat() method can also take strings as arguments:


Code Example Sample Output
const arr1 = ["Emil", "Tobias", "Linus"];
const myChildren = arr1.concat("Peter"); 		Emil,Tobias,Linus,Peter

Splicing an Array

The splice() method can be used to add new items to an array:


Code Example Sample Output
const fruits = ["Banana", "Orange", "Apple", "Mango"];
fruits.splice(2, 0, "Lemon", "Kiwi"); 		Banana,Orange,Lemon,Kiwi,Apple,Mango

The first parameter (2) defines the position where new elements should be added (spliced in).
The second parameter (0) defines how many elements should be removed.
The rest of the parameters ("Lemon", "Kiwi") define the new elements to be added.

The splice() method returns an array with the deleted items:


Code Example Sample Output
const fruits = ["Banana", "Orange", "Apple", "Mango"];
fruits.splice(2, 2, "Lemon", "Kiwi"); 		Banana,Orange,Lemon,Kiwi

Using splice() to Remove Elements. With clever parameter setting, you can use splice() to remove elements without leaving "holes" in the array:


Code Example Sample Output
const fruits = ["Banana", "Orange", "Apple", "Mango"];
fruits.splice(0, 1); 		Orange,Apple,Mango

Using splice() to Add Elements

This example uses splice() to add new items, without removing any items:


Code Example Sample Output
const fruits = ["Banana", "Orange", "Apple", "Mango"];
fruits.splice(2, 0, "Lemon", "Kiwi"); 		Banana,Orange,Lemon,Kiwi,Apple,Mango

Array copyWithin()

The copyWithin() method copies array elements to another position in an array, overwriting the existing values:


Code Example Sample Output
const fruits = ["Banana", "Orange", "Apple", "Mango"];
fruits.copyWithin(2, 0); 		Banana,Orange,Banana,Orange

The copyWithin() method is a mutable method. It does not create a copy of the array; it changes the original array. The method also returns the array, with the changes.


Flattening an Array

Flattening an array is the process of reducing the dimensionality of an array.
The flat() method creates a new array with sub-array elements concatenated to a specified depth:


Code Example Sample Output
const myArr = [[1,2],[3,4],[5,6]];
const newArr = myArr.flat(); 		1,2,3,4,5,6

JavaScript Array flatMap()

The flatMap() method first maps all elements of an array, and then creates a new array by flattening the array:


Code Example Sample Output
const myArr = [1, 2, 3, 4, 5, 6];
const newArr = myArr.flatMap(x => x * 2); 		2,4,6,8,10,12

JavaScript Array Const

Arrays declared with const cannot be reassigned, but their elements can still be changed.
You will learn more about this in the next chapter.


JavaScript Array Constructor

JavaScript has a built in array constructor new Array(). But you can safely use [] instead.

These two different statements both create a new empty array named points:


Code Example Sample Output
const points = new Array(); An empty array, using the constructor.
const points = []; An empty array, using an array literal.

These two different statements both create a new array containing 6 numbers:


Code Example Sample Output
const points = new Array(40, 100, 1, 5, 25, 10); An array of 6 numbers, using the constructor.
const points = [40, 100, 1, 5, 25, 10]; An array of 6 numbers, using an array literal.

Note: The new keyword can simplify, and produce unexpected results. See the exception below.


A Common Error

const points = [40]; is NOT the same as const points = new Array(40);


Code Example Sample Output
const points = [40]; 1
const points = new Array(40); 40

What if there are 2 numbers?


Code Example Sample Output
const points = [40, 100]; 2
const points = new Array(40, 100); 2

How to Recognize an Array

A common question is: How do I know if a variable is an array? The Array.isArray() method answers this question:


Code Example Sample Output
Array.isArray(document.getElementsByTagName("p")); false
Array.isArray([1, 2, 3, 4]); true
