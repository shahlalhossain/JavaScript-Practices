JavaScript Type Conversion

JavaScript variables can be converted to a new variable and another data type:
By the use of a JavaScript function, or automatically by JavaScript itself.

Converting Strings to Numbers

The global method Number() converts a value to a number. A numeric string converts to a number. An empty string converts to 0. Anything else converts to NaN.


Code Example Sample Output
Number("3.14");
Number("");
Number("99 88");
Number("John");
Method Description
Number()Returns a number, converted from its argument
parseFloat()Parses a string and returns a floating point number
parseInt()Parses a string and returns an integer

The Unary + Operator

The unary + operator can be used to convert a variable to a number.


Code Example Sample Output
let y = "5";   // y is a string
let x = + y;   // x is a number
let y = "John";   // y is a string
let x = + y;   // x is a number (NaN)

Converting Numbers to Strings

The global method String() can convert numbers to strings. It can be used on any type of numbers, literals, variables, or expressions.


Code Example Sample Output
String(x);   // returns a string from a number variable x
String(100 + 23);   // returns a string from a number from an expression

The Number method toString() does the same.

Code Example Sample Output
x.toString();
(123).toString();
(100 + 23).toString();

More Methods

Methods that can be used to convert numbers to strings:


Method Description
toExponential()Returns a string, with a number rounded and written using exponential notation
toFixed()Returns a string, with a number rounded and written with a specified number of decimals
toPrecision()Returns a string, with a number written with a specified length

Converting Dates to Numbers

The global method Number() can be used to convert dates to numbers.


Code Example Sample Output
let d = new Date();
Number(d);   // returns the number of milliseconds since 1970

Date objects can be converted to a number by using the method getTime().

Code Example Sample Output
let d = new Date();
d.getTime();

Converting Dates to Strings

The global method String() can convert dates to strings.


Code Example Sample Output
String(Date());

The toString() method does the same.

Code Example Sample Output
Date().toString();

Date Parts

JavaScript has methods to get each part of a date, as a number:


Method Description
getFullYear()Get the year
getMonth()Get the month
getDate()Get the day
getDay()Get the weekday
getHours()Get the hour
getMinutes()Get the minute
getSeconds()Get the second
getMilliseconds()Get the millisecond

Month is Zero Based

In JavaScript, the first month (January), has index 0.
To compensate, add 1 after conversion:


Code Example Sample Output
let date = new Date();
(date.getMonth() + 1).toString();

Month Name

Converting a month number to a name is done with a built-in method, or a lookup list.


Code Example Sample Output
let date = new Date();
date.toLocaleString('default', { month: 'long' });

Converting Booleans to Numbers

The global method Number() can also convert booleans to numbers.


Code Example Sample Output
Number(false);   // returns 0
Number(true);   // returns 1

Converting Booleans to Strings

The global method String() can convert booleans to strings.


Code Example Sample Output
String(false);
String(true);

The boolean method toString() does the same.

Code Example Sample Output
false.toString();
true.toString();

Automatic Type Conversion

When JavaScript tries to operate on a "wrong" data type, it will try to convert the value to a "right" type.


Code Example Sample Output
5 + null;   // returns 5
"5" + null;   // returns "5null"
"5" - 2;   // returns 3
"5" * "2";   // returns 10

Note: Strings can be added, subtracted, multiplied and divided. If you add a number and a string, JavaScript will treat the number as a string.

Automatic String Conversion

JavaScript automatically calls the variable's toString() function when you try to "output" an object or a variable.


Code Example Sample Output
document.getElementById("demo").innerHTML = myVar;   // if myVar = {name:"Fjohn"} // toString converts to "[object Object]"
document.getElementById("demo").innerHTML = myVar;   // if myVar = [1,2,3,4] // toString converts to "1,2,3,4"
document.getElementById("demo").innerHTML = myVar;   // if myVar = new Date() // toString converts to the date string
