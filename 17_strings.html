JavaScript Strings

A JavaScript string is zero or more characters written inside quotes.
You can use single or double quotes:


Code Example Sample Output
let carName1 = "Volvo XC60"; Double quotes.
let carName2 = 'Volvo XC60'; Single quotes.

Code Example Sample Output
<!DOCTYPE html>
<html>
<body>

  <h2>JavaScript Strings</h2>

  <p id="demo"></p>

  <script>
    let text = "John Doe";
    document.getElementById("demo").innerHTML = text;
  </script>

</body>
</html>

JavaScript Strings

John Doe

You can use quotes inside a string, as long as they don't match the quotes surrounding the string:


Code Example Sample Output
let answer1 = "It's alright"; Single quote inside double quotes.
let answer2 = "He is called 'Johnny'"; Single quotes inside double quotes.
let answer3 = 'He is called "Johnny"'; Double quotes inside single quotes.

String Length

To find the length of a string, use the built-in length property:


Code Example Sample Output
let text = "ABCDEFGHIJKLMNOPQRSTUVWXYZ";
let length = text.length; 		26

Escape Characters

Because strings must be written within quotes, JavaScript will misunderstand this string:


Code Example Sample Output
let text = "We are the so-called "Vikings" from the north."; SyntaxError: the string will be cut short at "Vikings".

The solution to avoid this problem, is to use the backslash escape character.
The backslash ( \ ) escape character turns special characters into string characters:


Code Result Description
\' ' Single quote
\" " Double quote
\\ \ Backslash

Code Example Sample Output
let text = "We are the so-called \"Vikings\" from the north."; We are the so-called "Vikings" from the north.

Six other escape sequences are valid in JavaScript:


Code Result
\b Backspace
\f Form Feed
\n New Line
\r Carriage Return
\t Horizontal Tabulator
\v Vertical Tabulator

Note: The 6 escape characters above were originally designed to control typewriters, teletypes, and fax machines. They do not make any sense in HTML.


Breaking up a Code Line

You can break up a code line within a text string with a single backslash:


Code Example Sample Output
document.getElementById("demo").innerHTML = "Hello \
Dolly!"; 		Hello Dolly!

The method above is not the preferred method. It might not have universal support. Some browsers will not allow spaces behind the backslash character.

The safest way to break up a string, is to use string addition:


Code Example Sample Output
document.getElementById("demo").innerHTML = "Hello " +
"Dolly!"; 		Hello Dolly!

Note: You cannot break up a code line with a backslash. This will work: "Hello Dolly!", but this will NOT work: \"Hello Dolly!".


JavaScript Strings as Objects

Normally, JavaScript strings are primitive values, created from literals: let x = "John";
But strings can also be defined as objects with the keyword new: let y = new String("John");


Code Example Sample Output
let x = "John";
let y = new String("John"); 		typeof x is "string", typeof y is "object".

Don't create Strings as objects. It slows down execution speed.
The new keyword complicates the code and can produce unexpected results:


Code Example Sample Output
let x = "John";
let y = new String("John");
(x == y)      // is true because x and y have equal values 		true
let x = "John";
let y = new String("John");
(x === y)     // is false because x and y have different types 		false

Comparing two JavaScript objects always returns false:


Code Example Sample Output
let x = new String("John");
let y = new String("John");
(x == y)      // is false because x and y are different objects 		false

Note: Objects cannot be compared. JSON.stringify() is the only safe way to compare objects for value equality.


JavaScript String Reference

For a complete reference, see the full String object reference.
The reference contains descriptions and examples of all String properties and methods.


Property / Method Description
length Returns the length of a string
at() Returns the character at a specified index (position) in a string
charAt() Returns the character at a specified index (position) in a string
charCodeAt() Returns the Unicode of the character at a specified index in a string
codePointAt() Returns the Unicode code point at a specified index in a string
concat() Joins two or more strings, and returns a copy of the joined strings
endsWith() Checks whether a string ends with specified string/characters
fromCharCode() Converts Unicode values to characters
includes() Checks whether a string contains the specified string/characters
indexOf() Returns the position of the first found occurrence of a specified value in a string
lastIndexOf() Returns the position of the last found occurrence of a specified value in a string
localeCompare() Compares two strings in the current locale
match() Searches a string for a match against a regular expression, and returns the matches
matchAll() Searches a string for all matches against a regular expression, and returns an iterator of the matches
normalize() Returns the Unicode Normalization Form of a string
padEnd() Pads a string at the end with another string until it reaches a given length
padStart() Pads a string at the start with another string until it reaches a given length
repeat() Returns a new string with a specified number of copies of an existing string
replace() Searches a string for a specified value, or a regular expression, and returns a new string where the specified values are replaced
replaceAll() Searches a string for all occurrences of a specified value, or a regular expression, and returns a new string where the specified values are replaced
search() Searches a string for a specified value, or regular expression, and returns the position of the match
slice() Extracts a part of a string and returns a new string
split() Splits a string into an array of substrings
startsWith() Checks whether a string begins with specified string/characters
substr() Extracts the characters from a string, beginning at a specified start position, and through the specified number of characters (deprecated)
substring() Extracts the characters from a string, between two specified indices
toLowerCase() Converts a string to lowercase letters
toUpperCase() Converts a string to uppercase letters
toString() Returns the value of a String object
trim() Removes whitespace from both ends of a string
trimEnd() Removes whitespace from the end of a string
trimStart() Removes whitespace from the start of a string
valueOf() Returns the primitive value of a String object

Note: All string methods return a new value. They do not change the original variable.
