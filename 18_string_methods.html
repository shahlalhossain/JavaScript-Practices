JavaScript String Methods

String methods help you to work with strings.
JavaScript primitive values, like strings, cannot have properties or methods because they are not objects.
But with JavaScript, methods and properties are also available to primitive values, because JavaScript treats primitive values as objects when executing methods and properties.


JavaScript String Length

The length property returns the length of a string:


Code Example Sample Output
let text = "ABCDEFGHIJKLMNOPQRSTUVWXYZ";
let length = text.length; 		26

Extracting String Characters

There are 4 methods for extracting string characters:

  • at(position)
  • charAt(position)
  • charCodeAt(position)
  • Property access [ ]

Code Example Sample Output
let text = "HELLO WORLD";
text.at(0);		 H
let text = "HELLO WORLD";
text.charAt(0);		 H
let text = "HELLO WORLD";
text.charCodeAt(0);		 72
let text = "HELLO WORLD";
text[0];		 H

Note: Property access can be a little unpredictable: it does not let you set new properties, and it does not work on strings created with new String().


Extracting String Parts

There are 3 methods for extracting a part of a string:

  • slice(start, end)
  • substring(start, end)
  • substr(start, length)

The slice() Method

slice() extracts a part of a string and returns the extracted part in a new string.
The method takes 2 parameters: start position, and end position (end not included).


Code Example Sample Output
let text = "Apple, Banana, Kiwi";
let part = text.slice(7, 13); 		Banana

If a parameter is negative, the position is counted from the end of the string:


Code Example Sample Output
let text = "Apple, Banana, Kiwi";
let part = text.slice(-12, -6); 		Banana

If you omit the second parameter, the method will slice out the rest of the string:


Code Example Sample Output
let text = "Apple, Banana, Kiwi";
let part = text.slice(7); 		Banana, Kiwi
let text = "Apple, Banana, Kiwi";
let part = text.slice(-12); 		Banana, Kiwi

The substring() Method

substring() is similar to slice().
The difference is that substring() cannot accept negative indexes.


Code Example Sample Output
let text = "Apple, Banana, Kiwi";
let part = text.substring(7, 13); 		Banana

If you omit the second parameter, substring() will slice out the rest of the string.


The substr() Method

substr() is similar to slice().
The difference is that the second parameter specifies the length of the extracted part.


Code Example Sample Output
let text = "Apple, Banana, Kiwi";
let part = text.substr(7, 6); 		Banana

If you omit the second parameter, substr() will slice out the rest of the string.
If the first parameter is negative, the position counts from the end of the string.

Note: substr() is an Annex B feature. Annex B features are not standard JS features, but are implemented in most browsers for compatibility reasons. New JavaScript code should avoid using it.


Replacing String Content

The replace() method replaces a specified value with another value in a string:


Code Example Sample Output
let text = "Please visit Microsoft!";
let newText = text.replace("Microsoft", "W3Schools"); 		Please visit W3Schools!

Note: The replace() method does not change the string it is called on. It returns a new string. The replace() method replaces only the first match. By default, the replace() method is case sensitive.

To replace case insensitive, use a regular expression with an /i flag (insensitive):


Code Example Sample Output
let text = "Please visit Microsoft!";
let newText = text.replace(/MICROSOFT/i, "W3Schools");		 Please visit W3Schools!

To replace all matches, use a regular expression with a /g flag (global match):


Code Example Sample Output
let text = "Please visit Microsoft and Microsoft!";
let newText = text.replace(/Microsoft/g, "W3Schools");		 Please visit W3Schools and W3Schools!

The replaceAll() Method

The replaceAll() method replaces all occurrences of a specified value with another value in a string:


Code Example Sample Output
let text = "Please visit Microsoft and Microsoft!";
let newText = text.replaceAll("Microsoft", "W3Schools"); 		Please visit W3Schools and W3Schools!

Note: replaceAll() was introduced in JavaScript 2021 (ES2021). It is not supported in Internet Explorer.


Converting to Upper and Lower Case

A string is converted to upper case with toUpperCase():


Code Example Sample Output
let text1 = "Hello World!";
let text2 = text1.toUpperCase(); 		HELLO WORLD!

A string is converted to lower case with toLowerCase():


Code Example Sample Output
let text1 = "Hello World!";
let text2 = text1.toLowerCase(); 		hello world!

The concat() Method

concat() joins two or more strings:


Code Example Sample Output
let text1 = "Hello";
let text2 = "World";
let text3 = text1.concat(" ", text2); 		Hello World

The concat() method can be used instead of the plus operator. These two lines do the same:


Code Example Sample Output
let text = "Hello" + " " + "World!"; Hello World!
let text = "Hello".concat(" ", "World!"); Hello World!

Trimming Strings

The trim() method removes whitespace from both sides of a string:


Code Example Sample Output
let text1 = "    Hello World!    ";
let text2 = text1.trim(); 		Hello World!

The trimStart() method removes whitespace only from the start of a string.
The trimEnd() method removes whitespace only from the end of a string.


Padding a String

JavaScript string padding is the process of adding characters to a string, to ensure it has a certain length.
padStart() pads a string from the start:


Code Example Sample Output
let text = "5";
let padded = text.padStart(4,"0"); 		0005

padEnd() pads a string from the end:


Code Example Sample Output
let text = "5";
let padded = text.padEnd(4,"0"); 		5000

Note: Padding methods were added to JavaScript in 2017.


Extracting String Repetition

The repeat() method returns a new string with a specified number of copies of the original string:


Code Example Sample Output
let text = "Hello world!";
text.repeat(2); 		Hello world!Hello world!

Note: The repeat() method was added to JavaScript in 2015.


Converting a String to an Array

A string can be converted to an array with the split() method:


Code Example Sample Output
"a,b,c".split(","); Splits on commas.
"a b c".split(" "); Splits on spaces.
"a|b|c".split("|"); Splits on pipe characters.

If you omit the separator, split() returns an array containing the whole string in index [0].
If the separator is "", the returned array will be an array of single characters:


Code Example Sample Output
let text = "Hello";
text.split(""); 		H,e,l,l,o
