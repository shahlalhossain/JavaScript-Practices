JavaScript Objects

Objects are variables too. But objects can contain many values.
This example creates an object with 3 properties, firstName, lastName, and age:


Code Example Sample Output
const person = {firstName:"John", lastName:"Doe", age:50}; An object literal with 3 properties.

What is an Object?

Values in JavaScript are always of a certain type. For example strings, numbers, objects, and so on.
In JavaScript, objects are king. If you understand objects, you understand JavaScript.

In JavaScript, an object is an unordered collection of related data, of primitive or reference types, in the form of "key: value" pairs. These keys can be variables or functions, and are called properties and methods, respectively, in the context of an object.

JavaScript objects are containers for named values, called properties and methods.


Object Properties

Properties are the values associated with a JavaScript object.
A JavaScript object is a collection of unordered properties.
Properties can usually be changed, added, and deleted, but some are read only.


Accessing Object Properties

You can access object properties in two ways:


Code Example Sample Output
person.lastName; Dot notation.
person["lastName"]; Bracket notation.

JavaScript Methods

Methods are actions that can be performed on objects.
Methods are stored in properties as function definitions.


Code Example Sample Output
const person = {
  firstName: "John",
  lastName : "Doe",
  id        : 5566,
  fullName : function() {
    return this.firstName + " " + this.lastName;
  }
}; 		The fullName property is a method that returns the person's full name.

In the example above, this refers to the person object.


Accessing Object Methods

You access an object method with the following syntax:


Code Example Sample Output
objectName.methodName() General syntax for calling a method.

Code Example Sample Output
<!DOCTYPE html>
<html>
<body>

  <h2>JavaScript Objects</h2>

  <p>In JavaScript, methods are functions stored as object properties.</p>

  <p id="demo"></p>

  <script>
    const person = {
      firstName: "John",
      lastName : "Doe",
      id        : 5566,
      fullName : function() {
        return this.firstName + " " + this.lastName;
      }
    };

    document.getElementById("demo").innerHTML = person.fullName();
  </script>

</body>
</html>

JavaScript Objects

In JavaScript, methods are functions stored as object properties.

John Doe

Note: If you access the fullName property, without (), it will return the function definition.


The this Keyword

In a function definition, this refers to the "owner" of the function.
In the example above, this is the person object that "owns" the fullName function.
In other words, this.firstName means the firstName property of this object.


What is this?

In JavaScript, the this keyword refers to an object.
Which object depends on how this is being invoked (used or called).
The this keyword refers to different objects depending on how it is used:

  • In an object method, this refers to the object
  • Alone, this refers to the global object
  • In a function, this refers to the global object
  • In a function, in strict mode, this is undefined
  • In an event, this refers to the element that received the event
  • Methods like call(), apply(), and bind() can refer this to any object

Displaying JavaScript Objects

When displaying objects, with the innerHTML property, you have to convert the object to a string, or display selected properties.


Displaying with Object.values()

You can use the built-in method Object.values() to display the values of a JavaScript object as an array:


Code Example Sample Output
const person = {
  firstName: "John",
  lastName: "Doe",
  age: 50,
  eyeColor: "blue"
};
document.getElementById("demo").innerHTML = Object.values(person); 		John,Doe,50,blue

Displaying Properties using for...in

You can loop through object properties with a for...in loop.


Code Example Sample Output
const person = {
  firstName: "John",
  lastName: "Doe",
  age: 50,
  eyeColor: "blue"
};

let text = "";
for (let x in person) {
  text += person[x] + " ";
} 		John Doe 50 blue

Displaying Properties using Object.entries()

You can use the Object.entries() method to loop through object properties.


Code Example Sample Output
const fruits = {Bananas:300, Oranges:200, Apples:500};

let text = "";
for (let [key, value] of Object.entries(fruits)) {
  text += key + ": " + value + "<br>";
} 		Bananas: 300
Oranges: 200
Apples: 500

JavaScript Object Constructors

Sometimes we need a "blueprint" for creating many objects of the same "type".
The way to create an "object type", is to use an object constructor function.


Code Example Sample Output
<!DOCTYPE html>
<html>
<body>

  <h2>JavaScript Constructors</h2>

  <p id="demo"></p>

  <script>
    function Person(first, last, age, eye) {
      this.firstName = first;
      this.lastName = last;
      this.age = age;
      this.eyeColor = eye;
    }

    const myFather = new Person("John", "Doe", 50, "blue");
    const myMother = new Person("Sally", "Rally", 48, "green");

    document.getElementById("demo").innerHTML =
    "My father is " + myFather.age + ". My mother is " + myMother.age + ".";
  </script>

</body>
</html>

JavaScript Constructors

My father is 50. My mother is 48.

Note that the this keyword, used in the constructor function, is not a value. It is a reference to the object that "receives" the function call.
It is a good practice to name constructor functions with an upper-case first letter.


Object Types (Blueprints) (Classes)

The examples above are limited in many situations. They only produce a single object.
Sometimes we need a "blueprint" for creating many objects of the same "type".
The way to create an "object type", is to use an object constructor function. It is considered good practice to use capital first letter for constructor functions.


Code Example Sample Output
function Person(first, last, age, eye) {
  this.firstName = first;
  this.lastName = last;
  this.age = age;
  this.eyeColor = eye;
} 		A constructor function for creating Person objects.

Creating Objects

When you have an object constructor, you can use the new keyword to create new objects of the same type:


Code Example Sample Output
const myFather = new Person("John", "Doe", 50, "blue");
const myMother = new Person("Sally", "Rally", 48, "green"); 		Two separate Person objects, each with their own property values.

Note: The this keyword in a constructor function does not have a value. It becomes the new object when the constructor is used to create an object.


Adding a Property to an Object

Adding a new property to an existing object is easy:


Code Example Sample Output
myFather.nationality = "English"; The nationality property is added only to myFather, not to myMother.

Note: The new property is added only to this object; it is not added to any other object of the same type.


Adding a Method to an Object

Adding a new method to an existing object is also easy:


Code Example Sample Output
myFather.name = function() {
  return this.firstName + " " + this.lastName;
}; 		The name method is added only to myFather, not to myMother.

Note: The new method is added only to this object; it is not added to any other object of the same type.
